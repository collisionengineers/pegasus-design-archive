# Pegasus design archive

This repository holds material moved out of
[collisionengineers/pegasus](https://github.com/collisionengineers/pegasus) on
14 October 2026 to keep that repository small.

- `vNN_planning/` folders are the Stage 1 mockup rounds. They used to live in
  `design/planning-and-old-designs/` in the main repository. New rounds are
  written here (see the `razor-html-mockup-creation` skill in the main repository).
- `old-reference/` holds files that had already been deleted from the main
  repository but were still in its history. Each keeps its original path below
  `old-reference/`.

The history of every file is kept. This is reference material, not current
requirements.
