## Changes

- **S1**: Release notes, Report a problem and Change password move into the Account dialog body; the foot keeps Close and Sign out.
- **S3**: The command palette's Cases icon matches the rail's Cases icon.
- **S4**: The utility bar's freshness line goes; the rail health line keeps the one clock.
- **U1**: The page subtitle and the narration sentences that carry no consequence go; the Attached, Discarded and Pending sentences stay as they are.
- **U3**: The Principal filter lists every Principal that appears in the queues, and Page N shows only when there is a previous or next page.
- **U4**: Create case: each field is a label and input pair in the form grid, the Extracted from sentences and the provenance word go, and a value taken from the file carries the Extracted pill.
- **U5**: Triage: Link case uses the Case picker with the label Case / PO, response evidence options read time and mailbox only, and Documents rows gain the View button beside Save as.
- **U6**: The first card no longer repeats the facts the ribbon above it already shows.
- **U7**: The Principal filter sits in the list head beside the count, so the band that held one select goes.
- **U8**: Quick detail shows what the row does not: one compact fact grid without repeating Case/PO, registration and claimant.
- **U9**: Review new Case proposal is the decision's primary button; Find a Case and Leave undecided stay secondary.
- **U10**: The form is bounded and short fields share rows, so controls are not stretched across the page; Create case sits at the form's end.
- **U11**: Add to an existing case is the one strong action and its eligible Cases sit right under it; Edit record is a plain button.
- **U12**: Resolve lists its actions as one even column, Link to Case first, with Close with reason set apart at the bottom.
- **W8**: Cases · With Engineer: the Engineer cell reads Unassigned where the Case has no Engineer.
