# Upload — Panels

Each of the 5 candidate designs (`UB1`–`UB5`) composes existing Pegasus surface primitives from `site.css` and `upload.css`:

- **Design A (`UB1`):** `.pane-layout.up-a-workbench` with left `.pane.up-a-pane-left` (`.up-a-case-banner`, `.up-drop`, `.fact-grid.up-a-facts`) and right `.pane.up-a-pane-right` (`[data-select-files]`, `.up-empty-slate`, `ul.up-file-list`, `.pane-foot`).
- **Design B (`UB2`):** Optional `.panel.up-b-case-ribbon` (5 `.ribbon-item` cells) above `.panel.up-b-panel` (`.up-drop`, `.up-b-files`, and right-hand `aside.up-b-guide` format reference card).
- **Design C (`UB3`):** `.panel.up-c-panel` with `.presence-strip.up-c-case-strip` (on Case upload), horizontal `.up-c-dropbar`, and `.up-c-ledger` (`Selected files`, `Destination`, `Remove`).
- **Design D (`UB4`):** `.up-d-split` pairing left `aside.panel.context-card.up-d-left` (destination card + 2×2 `.fact-grid`) with right `section.panel.up-d-right` (`.up-drop` + `.up-d-files` + `.panel-foot`).
- **Design E (`UB5`):** Bounded `880px` `.record.up-e-sheet` with dark `.record-head.up-e-head`, `.record-accent`, 4 `.up-e-kinds` category tiles, `.up-drop`, `.up-e-files`, and `.record-bar.up-e-foot`.
